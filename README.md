# ❄️ Hidden World – Antarctica

Welcome to **Hidden World – Antarctica**, a website dedicated to exploring the beauty, mystery, and wonders of the coldest continent on Earth.

Discover breathtaking Antarctic landscapes, interesting facts, travel information, and a collection of beautiful images through a simple and interactive website.

## 🌍 Live Website

[Visit Hidden World – Antarctica](https://antarcticahiddenworld.vercel.app)

## ✨ Features

- ❄️ Beautiful Antarctica-themed design
- 🧊 Stunning image gallery featuring Antarctic landscapes
- 🌎 Interesting facts about Antarctica
- 🚢 Information about how to travel to Antarctica
- 🎒 Travel packing checklist
- 🌓 Light and dark mode
- 📱 Responsive design for mobile, tablet, and desktop
- 🖼️ Interactive image slider and lightbox
- 🎥 Background video section
- 📌 Smooth navigation and scroll-to-top button
- 🔗 Social media links

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactive features and functionality
- **Unsplash** – Beautiful photography

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/magumodestin/antarcticahiddenworld.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## 🌐 Deployment

This website is deployed using **Vercel**.

To deploy your own version:

1. Push your project to GitHub.
2. Log in to [Vercel](https://vercel.com/).
3. Import your GitHub repository.
4. Configure the project.
5. Deploy your website.

The purpose of this project is to share the beauty and fascinating information about Antarctica while creating an enjoyable and interactive web experience.
